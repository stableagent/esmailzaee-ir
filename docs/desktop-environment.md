# Desktop Environment

## Concept

esmailzaee.ir behaves visually like a small Linux desktop rather than a conventional portfolio.

## Desktop elements

### System bar

Displays:

- site identity
- current section
- locale
- lightweight clock/status information

### Desktop files

Examples:

- about.toon
- profile.toon
- activity.toon
- skills.toon
- contact.toon

### Directories

Examples:

- projects/
- skills/
- links/

### Windows

Opening a file displays its content in a desktop window. Windows are UI representations of routes/content; they are not operating-system processes.

### Terminal

The terminal supports a deliberately small, safe command vocabulary:

- help
- ls
- pwd
- cat
- open
- clear
- whoami

Commands operate only on the site's public content model.

The terminal must never execute arbitrary shell commands.

## Navigation

Every important desktop item has a normal URL equivalent. A user can therefore navigate with or without interacting with the simulated desktop.

## Accessibility

- keyboard navigation
- visible focus state
- semantic buttons/links
- reduced-motion support
- readable text contrast
- no essential information available only through drag/drop

## Responsive behavior

Desktop mode is the primary visual metaphor, but on narrow screens the layout becomes a touch-friendly workspace. Files remain accessible and windows become full-width panels where necessary.
